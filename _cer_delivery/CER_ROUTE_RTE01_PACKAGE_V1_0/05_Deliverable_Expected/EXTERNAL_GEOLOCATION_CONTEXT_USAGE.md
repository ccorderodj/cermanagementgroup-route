# External Geolocation Context — Usage Rule

CER will provide a separate MD generated from another developer/agent's experience building a geolocation-based application.

The CER Route team must review it during RTE01.

## Use it to understand

- technologies/tools previously used;
- platform limitations encountered;
- geolocation accuracy challenges;
- background/foreground behavior;
- browser/mobile restrictions;
- permission issues;
- battery implications;
- data/route issues;
- approaches that worked;
- approaches that failed;
- unresolved issues.

## Do not treat it as

- CER Route architecture;
- mandatory technology selection;
- mandatory provider selection;
- approved implementation instructions;
- product requirements.

The RTE01 report must explicitly identify which lessons are applicable to CER Route and which are not.
